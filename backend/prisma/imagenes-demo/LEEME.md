# Imágenes de demo del menú (Fase 16B)

Ilustraciones planas de los 8 productos del seed, **generadas para este
proyecto** (SVG escrito a mano con la paleta del equipo). No vienen de ningún
banco de imágenes ni tienen derechos de terceros.

`npm run seed:imagenes` (ver `prisma/seed-imagenes.ts`) las pasa a PNG, las
procesa igual que una foto subida desde `/catalogo` (WebP de 800 y 400 px) y
se las asigna a los productos del mismo nombre.
